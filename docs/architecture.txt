   ============================================================================
   tools/ + eval/baselines/  -- dev utilities, outside the request/response
   pipeline above (not wired into run/chat/markup/eval)
   ============================================================================
   - compare_models.py    same pair, same credential, different model names,
                           tokens/latency side by side
   - backend_compare.py   multi-backend cost/latency comparison
                           (scaffolded -- needs a 2nd credential to actually run)
   - visual_diff.py       naive, independent greedy matcher + human-in-the-loop
                           HTML debug viewer (deliberately not the real engine,
                           a sanity check against it)
